## Landing page

`index.html` es una landing estática de Grupo Dynamic (HTML y CSS, sin dependencias ni paso de compilación). Las imágenes en `assets/img/` salen de la presentación corporativa.

Para verla, abre `index.html` en el navegador. Para publicarla, sirve la carpeta tal cual (GitHub Pages, Netlify o el hosting de grupodynamic.es).

Pendiente: sustituir el logo dibujado en SVG por el archivo oficial y los nombres de clientes por sus logos, si se dispone de ellos.
